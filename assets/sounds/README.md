# 音频资源目录（assets/sounds）

本目录存放语音播报相关的音频文件。

## 播报策略（优先级从高到低）

1. **预录人声 WAV**（本目录，文件名见下表）——音质最清晰、最可靠，盲杖这类无障碍设备首选。
2. **espeak-ng 实时合成**——当某个预录文件缺失时，自动用 `nodes/audio.py` 把对应文案合成播放，保证不静默。
3. **占位蜂鸣** `fallback_alert.wav`——连 espeak 都不可用时的最后有声反馈（不是真正的中文播报）。

> 你只需把下表文件按名放进本目录即可生效；没放的文件会回退到 espeak，不会让系统变哑。

## 录制要求

- 格式：**WAV，16-bit PCM**；单声道或双声道均可；采样率 16000 / 22050 / 44100 都可（paplay 自适应）。
- 建议：语速比平时稍慢、吐字清晰、背景安静；一句一文件，不要拼接多句。
- 文件名务必小写、含下划线，避免中文或空格（防止路径解析问题）。

## 自检

1. 程序启动时会在控制台打印预录音频就绪情况，例如：
   `预录音频: 已就绪 12/17，缺失 5 个（将回退 espeak）` 并逐条列出缺的文件名。
2. 进入容器后也可执行：`bash sh/audio_check.sh`（验证播放链路本身）。
